# 나라가쏜다 🇰🇷

> 복지로, 정부24, 온통청년, K-Startup 등 여러 공공기관에 흩어진 복지 정책과 지원사업을 한곳에서 찾고, 내 조건에 맞는 혜택을 빠르게 확인하는 통합 복지 탐색 서비스입니다.

**나라가쏜다**는 사용자가 자신에게 필요한 복지 정보를 찾기 위해 여러 정부 사이트를 일일이 돌아다녀야 하는 불편을 줄이기 위해 만든 서비스입니다. 정책명, 혜택, 담당 기관을 검색하거나 지역·연령·관심 분야 등의 조건을 설정하면 관련 정책을 한 화면에서 비교할 수 있습니다.

웹 서비스와 앱인토스 미니앱을 함께 제공하며, 공공데이터 원문을 기반으로 정책 정보를 정규화하고 중복 항목을 제거해 모바일에서도 빠르게 탐색할 수 있도록 구성했습니다.

## 왜 만들었나요?

정부와 지방자치단체의 지원사업은 종류가 많고 제공 기관도 다양합니다. 좋은 제도가 있어도 존재를 모르거나, 대상 조건과 신청 방법을 한눈에 파악하기 어려워 놓치는 경우가 생깁니다.

나라가쏜다는 이 문제를 다음과 같이 해결합니다.

- 여러 공공기관의 정책 데이터를 하나의 형식으로 통합합니다.
- 사용자의 지역, 나이, 가구·주거·고용 상황을 바탕으로 관련 혜택을 좁혀 줍니다.
- 지원 내용, 신청 대상, 신청 방법, 담당 기관과 원문 출처를 한 카드에서 보여 줍니다.
- 모바일 환경에서 검색부터 상세 확인, 저장까지 짧은 흐름으로 이용할 수 있게 합니다.

## 주요 기능

### 통합 정책 검색

복지로, 정부24, 온통청년, K-Startup 등에서 제공하는 복지·행정·청년·창업 지원 정보를 통합합니다. 정책명뿐 아니라 기관명, 지원 내용, 대상 키워드로도 검색할 수 있습니다.

### 조건별 필터와 맞춤 정렬

지역, 연령, 생애주기, 관심 분야 등을 이용해 수많은 정책 중 나와 관련성이 높은 항목을 찾습니다. 공공데이터에 조건이 부족한 경우에는 제목과 설명의 신호를 함께 활용해 결과 품질을 보완합니다.

### 한눈에 보는 정책 카드

각 정책의 핵심 혜택, 지원 대상, 신청 방법, 운영 기관, 지역, 마감 정보와 공식 출처를 읽기 쉬운 카드 형태로 제공합니다. 실제 신청 전에는 원문 페이지에서 최신 공고와 세부 자격을 다시 확인할 수 있습니다.

### 저장과 다시 보기

관심 있는 정책을 저장해 두고 나중에 다시 확인할 수 있습니다. 앱인토스 환경에서는 로그인 세션을 활용한 사용자별 저장 흐름도 지원합니다.

### AI 맞춤 복지 카드

사용자가 별도로 동의한 경우 나이, 지역과 현재 상황을 바탕으로 후보 정책을 분석해 추천 근거, 예상 혜택, 확인해야 할 자격, 준비서류와 신청 절차를 정리합니다. AI는 새로운 정책을 임의로 만들지 않고 서비스가 확보한 후보 정책 안에서만 안내하도록 설계했습니다.

### 웹·앱인토스 동시 지원

Next.js 웹 서비스와 Apps in Toss용 모바일 미니앱을 한 저장소에서 관리합니다. 작은 화면과 WebView에서도 초기 화면이 빠르게 열리도록 데이터 전송량과 캐시 전략을 최적화했습니다.

## 기술 스택

- **Frontend / Backend:** Next.js 16 App Router, React 19, TypeScript
- **Styling:** Tailwind CSS
- **Data processing:** Cheerio, 공공데이터 OpenAPI, RSS·웹 데이터 정규화
- **AI:** Gemini 기반 자연어 검색, OpenAI 기반 맞춤 복지 카드
- **Mobile:** Apps in Toss, Granite, Vite
- **Storage:** 브라우저 저장소 및 Redis 호환 REST 저장소
- **Deployment:** Vercel

## 프로젝트 구조

```text
kor-welfare-hub/
├─ src/
│  ├─ app/                 # Next.js 페이지와 API 라우트
│  ├─ components/          # 검색, 정책 카드, 상세 화면, 온보딩 UI
│  └─ lib/
│     ├─ ai/               # 자연어 분석 및 추천 로직
│     ├─ scrapers/         # 공공데이터 수집·변환·캐시
│     ├─ filter.ts         # 검색 및 필터링
│     ├─ profile.ts        # 사용자 조건과 정책 매칭
│     └─ types.ts          # 공통 정책 데이터 모델
├─ apps-in-toss/           # 앱인토스 미니앱
├─ scripts/                # 데이터 동기화 스크립트
└─ public/                 # 아이콘 등 정적 자산
```

## 로컬 실행

### 1. 저장소 복제

```bash
git clone https://github.com/fogtemplar/kor-welfare-hub.git
cd kor-welfare-hub
```

### 2. 패키지 설치

```bash
npm install
```

### 3. 환경변수 설정

프로젝트 루트에 `.env.local`을 만들고 사용할 데이터 소스의 API 키를 설정합니다.

```env
BOKJIRO_API_KEY=
GOV_SERVICE_API_KEY=
GOV24_API_KEY=
YOUTHCENTER_API_KEY=
KSTARTUP_API_KEY=

# 선택: AI 기능
GEMINI_API_KEY=
OPENAI_API_KEY=
```

모든 키가 필수인 것은 아닙니다. 설정된 데이터 소스만 수집에 사용되며, 토스 로그인·결제·서버 저장 기능은 별도의 운영 환경변수가 필요합니다. 실제 키와 인증서는 저장소에 커밋하지 마세요.

### 4. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인합니다.

## 설계상 특징

- 정책 페이지와 API 응답에 캐시를 적용해 외부 공공 API 호출량을 줄였습니다.
- 첫 화면에는 필요한 일부 데이터만 전달하고, 나머지는 초기 렌더링 뒤 API에서 받아 모바일 파싱 부담을 낮췄습니다.
- 서로 다른 출처의 카테고리, 지역, 대상과 생애주기 표현을 공통 규칙으로 정규화합니다.
- 출처가 다른 유사 정책은 제목과 기관 정보를 이용해 중복 노출을 줄입니다.
- AI 추천 결과에도 공식 원문 출처를 함께 제공하고, 확인되지 않은 금액·기한·자격을 단정하지 않도록 제한합니다.

## 안내 및 면책

나라가쏜다는 공공기관이 공개한 정보를 수집·정리해 탐색을 돕는 서비스이며 정부기관이 아닙니다. 복지 급여의 신청, 심사 또는 지급을 대행하지 않습니다.

정책 내용과 신청 기간은 운영 기관의 사정에 따라 변경될 수 있습니다. 서비스의 안내와 AI 분석은 참고용으로 활용하고, 신청 전 반드시 연결된 공식 원문 또는 담당 기관을 통해 최신 내용과 실제 자격을 확인해 주세요.
